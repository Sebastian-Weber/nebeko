# Nebeko

An AI-assisted workflow tool for German utility billing (Nebenkostenabrechnung), designed and built end-to-end from a real user problem.

## What This Is

Identified through observing a user, not from personal landlord experience: utility cost statements (Nebenkostenabrechnungen) are dense, hard to parse, and easy to get wrong. Nebeko walks through the document and surfaces what actually matters.

## Tech Stack

| Layer | Tool |
|---|---|
| Frontend | React, TypeScript, Tailwind CSS |
| Tracking | PostHog (consent-gated, DSGVO-compliant) |
